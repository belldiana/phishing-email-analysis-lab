# Phishing Email Analysis Report

In this TryHackMe lab, six phishing cases were analyzed. In these cases, 
different and common techniques were identified, like social engineering, 
brand impersonation, malicious attachments, tracking pixels, and link 
manipulation, with the final goal of stealing user credentials, among 
others, as part of TryHackMe's Phishing Emails 2 room.
